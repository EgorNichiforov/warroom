# War Room · user guide

The same guide lives inside the app: **Where do I…?** (on the Day card) → *How this app works, in one minute*, and every screen has a line under its title saying what it is for.

## The six places

1. **Day.** One card: the one thing to do now and why. "I have … min" fits it to your time.
2. **The + button.** Anything on your mind: a task, an idea, money, an owner's answer, calls made elsewhere. It is filed for you; what cannot be filed waits in Unprocessed.
3. **Work.** The call queue and the pipeline.
4. **Learn.** Say how much time you have; you get one session.
5. **Week.** The weekly review, then month, quarter and year.
6. **Where do I…?** Type what you want in plain words.

## When you want to…

| You want to | Type in "Where do I…?" |
|---|---|
| Know what is going on | the whole situation |
| Find anything you recorded | find a record |
| See where your records contradict each other | records disagree |
| See where the sales funnel stops | funnel |
| See the business as money | business economics |
| Work a goal back to today | how my goals connect |
| Try numbers before committing | scenario |
| Weigh a big choice | compare options |
| Get a second opinion that can only propose | ask a role |
| See what you got wrong while learning | weak spots |
| Check the app itself is healthy | app health |
| Check whether any of this is helping | is War Room actually working for me |

## Rules the app keeps

- One thing ranks your day: Mission Control. Nothing else does.
- A number with no measurement says so. A rate is shown only when the sample is big enough.
- Nothing is entered, merged or deleted for you. Roles and checks propose; you approve.
- The phone's back button goes one step back; on Day, a second press leaves.

## If something looks wrong

Open **System health**. Export a backup file from Settings before anything else if storage is high. A backup can be imported again on any device: it merges, it does not overwrite.
